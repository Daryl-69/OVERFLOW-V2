### Why it feels "mock"
1. **Synthetic ward at lat/lon (0,0).** The map you see is not Indore. `data/streets/` is empty.
2. **Default dashboard tab is a replay** of precomputed `data/scenarios/demo.json` — nothing is computed live.
3. **Live intake borrows a simulated history.** Baselines and travel times come from the simulator, so even a real photo is scored against fake households.
4. **Demo photo is synthetic** (`reader/synth.py`), and turbidity has no NTU calibration from real samples.
5. **Zero AWS.** No boto3, Bedrock, Strands, Lambda, DynamoDB, Step Functions, SNS or Amplify anywhere. For an AWS hackathon, judges will see a local Python app.
6. **No agent, no human-approval step** — the pattern your winner analysis flagged as decisive.

**Bottom line:** the science is about 85 % done and well ahead of most hackathon entries. The hackathon story (AWS + agent + real Indore) is about 0 % done. Don't rewrite the algorithms. Wrap them.

## 2. Target architecture (reuse-first)

```
Phone ─► API Gateway ─► presigned URL ─► S3 photos/
                                        │ (ObjectCreated)
                                        ▼
                     Lambda "reader"  (container image: upstream.reader + opencv)
                                        │ PutItem
                                        ▼
                  DynamoDB  Readings | Households | Incidents
                                        │ Streams (filter: level=red, or ≥2 amber)
                                        ▼
                  Step Functions "IncidentFlow"
                    1. Lambda "locate"   (upstream.locate.triangulate on Indore graph from S3)
                    2. Strands Incident Agent on Bedrock (Claude): drafts incident +
                       advisories, requests extra strips, via tools
                    3. waitForTaskToken ◄── engineer Approve/Reject (dashboard)
                    4. SNS: boil-water SMS/email to downstream homes + field crew
                                        │
                  Amplify-hosted dashboard (existing Leaflet app, pointed at the API)
```

### Strands agent tools (thin wrappers over existing code)
- `get_incident_readings(incident_id)`: DynamoDB query
- `run_triangulation(incident_id)`: invokes the locate Lambda, returns dig spot, 90 % region, ring
- `downstream_households(segment)`: `advisories.py`
- `request_strip_tests(households)`: `planner.nearby_requests`, queues SNS
- `draft_advisory(lang="hi|en")`: LLM text, Hindi + English
- `submit_for_approval(plan)`: sends the Step Functions task token to the dashboard

The agent proposes the actions and an engineer approves them. Nothing goes out to residents without a human click.
